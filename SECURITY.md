# Security reporting

[简体中文](docs/zh-CN/SECURITY.md)

Report suspected vulnerabilities privately through the repository's Security tab when private vulnerability reporting is enabled. If unavailable, ask the owner for a private channel before sharing technical details.

Include the affected commit or build, Windows version and configuration, the expected and observed impact, and the minimum reproducible steps in an authorized environment. Sanitize evidence and keep credentials, monitored files, packet captures, and personal system data out of public issues. See the [security standard](docs/standards/SECURITY.md) for triage and validation.
