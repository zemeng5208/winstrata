# WinStrata

[简体中文](README.zh-CN.md)

WinStrata is a modular, local-first Windows system observability platform. It is designed to trace system changes, analyze software lifecycles, and inspect network activity on Windows 10 and Windows 11 x64.

The project is at the design and engineering foundation stage. PR 000 establishes the scope, standards, and planned development sequence for owner review. A runnable development build will be delivered after the [acceptance plan](docs/roadmap/ACCEPTANCE.md) is met.
