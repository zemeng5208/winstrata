# Contributing

[简体中文](docs/zh-CN/CONTRIBUTING.md)

Read [AGENTS.md](AGENTS.md), the [project plan](docs/roadmap/PLAN.md), and the [Git and PR standard](docs/standards/GIT_AND_PR.md). Work from the approved base on a development branch. Before implementation, identify the plan ID, scope, prerequisites, merge position, and evidence required for acceptance. Get approval for changes to scope, architecture, dependencies, or mandatory rules.

Submit an English PR using the [review template](.github/pull_request_template.md). Describe the actual diff, test environment, outcomes, and pending checks. Update both language versions of affected documentation. The project owner reviews and merges PRs in the approved order. Raise security concerns through the [security reporting process](SECURITY.md).
