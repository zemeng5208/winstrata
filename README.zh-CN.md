# WinStrata

[English](README.md)

WinStrata 是一款模块化、本地优先的 Windows 系统可观测性平台，面向 Windows 10 和 Windows 11 x64，计划提供系统变更追踪、软件生命周期分析与网络观测。

项目处于设计和工程基线阶段。PR 000 将范围、规范和拟定开发顺序提交所有者审核。达到[整体验收标准](docs/zh-CN/roadmap/ACCEPTANCE.md)后交付可运行的开发版。
