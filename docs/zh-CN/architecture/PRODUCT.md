## 产品定位和明确边界

WinStrata 是 Windows 全层级系统状态监视、系统变更追踪、软件生命周期分析、网络可观测与本地扩展平台，不是普通任务管理器、传统杀毒软件、Git 替代品或 AI Agent 管理平台。

| 维度 | 已确认要求 |
|---|---|
| 运行 | 用户主动启动；可选开机自启动，默认关闭；未运行时不实时采集 |
| 用户范围 | 当前 Windows 用户及相关系统级公共活动；不主动监视其他用户的私人数据 |
| 系统范围 | Windows 10/11 x64；不运行于 Linux，不专门支持 Server，不做 ARM64/x86 第一版 |
| 文件范围 | 磁盘、分区、目录、存储设备由用户选择；新设备不自动纳入 |
| 功能原则 | 监视、记录、分析、查询为主；仅 StrataRescue 是受限系统修改例外 |
| 网络 | 可以联网获取更新、市场索引等，不依赖专有云端服务；不上传监视数据、遥测、日志、文件或哈希 |
| 交互 | 独立桌面 GUI；无面向用户的通用 CLI；MCP 为明确批准的本机 Agent 接口例外 |
| AI | 不内置 Agent、模型、推理、任务调度或模型 API Key |
| 版本控制 | 不重复 Git 的文件内容版本管理和内容 diff；重点是系统级状态、元数据、来源及实时事件 |
| 语言 | 简体中文、完整英文；其他系统语言默认英语；运行时切换 |
| 发行 | 开发版，完整源码、SDK、调试和开发工具；不关闭 Windows 安全保护作为运行条件 |

发布插件或脚本是明确的用户主动对外发布行为，必须确认；与禁止自动上传监视数据相互独立。普通联网请求不可夹带系统监视数据。外部 Agent 是否将其读取的数据传给模型服务由外部平台负责，WinStrata 不主动上传，并明确说明这一边界。

不承诺全知全能：停机期间事件、不可观测的内核活动、未选范围、被隔离的其他用户、加密网络内容、未授权或不可见的网络拓扑、硬件不支持的指标，必须如实标注。历史推断不冒充实际监视事实。

### 4.1 软件生命周期完整链路

首次启动根据所选范围建立基线，扫描现有软件、文件、注册表、环境变量、服务、驱动、计划任务及疑似历史残留。监视启动前信息只能尽可能重建；后续用实时事件和增量基线更新。手动用户快照与基础采集基线独立。

自动识别 MSI、MSIX、EXE、便携式软件、脚本安装、软件更新/卸载等，结合进程树、系统服务间接调用、共享依赖、实际变更证据进行归因。手动会话可指定安装器、脚本、进程、便携软件；支持开始/结束状态比较。不能把时间重合的所有系统变化归入同一软件。

软件档案呈现所有可确认路径、注册表前后值、环境变量、服务/驱动、启动项/计划任务、Shell 集成（文件关联、COM、右键菜单）、网络连接、资源、签名、依赖与时间线。系统组件、共享运行库与归属不明项目独立标记。卸载残留给出判断依据、可信度、具体位置；第一版不提供普通清理或强制卸载。

磁盘占用按主程序、配置、缓存、日志、用户数据、更新、下载、残留和共享依赖分类，提供明细和历史趋势；区分逻辑与实际占用，处理硬链接、稀疏文件等，避免重复统计。按需哈希、复用索引及增量扫描，不持续全盘读取。

### 4.2 其他监视完整性

监视所选当前用户相关文件权限/所有权、注册表、环境变量、进程、服务、驱动、启动项、任务、网络、防火墙、证书、安全配置、系统更新及 Windows 可选组件；原生接口无法观察的指标不能以 0、假数据或旧缓存冒充实时。StrataTrace 提供跨来源变更视图而不重复 StrataRegistry 等插件的采集。StrataSecurity 与 StrataTrust/StrataUpdate 等共享事实来源，不重复扫描。所有相关查询可按插件授权暴露 MCP。
