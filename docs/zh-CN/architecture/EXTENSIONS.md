## 插件、脚本与市场

### 5.1 生命周期、能力和隔离

计划 014 把原生契约和进程生命周期记在[插件](PLUGINS.md)。计划 015 把语言 SDK 和操作系统隔离记在[运行时](RUNTIMES.md)。25 个采集实现、用户选择启用、统一市场和签名事务回退仍属于后续计划。

- 独立加载、启动、暂停、停止、禁用、更新、故障恢复；第三方可卸载，官方内置不可卸载。禁用释放专属资源、订阅和任务；共享采集按引用保留。历史数据默认保留。
- 运行中动态安装、更新、替换和禁用，尽可能不重启 GUI/Windows、不影响无依赖模块；驱动等不能安全热替换时明确提示。更新失败事务回退、配置和数据迁移、依赖版本校验。
- 统一能力声明、依赖、事件、服务、前端组件、页面/导航/仪表盘、权限、语言资源、MCP 工具和脚本接口。Manifest 候选 `manifest.json`，格式由开发 Agent 提案；不预先锁定字段实现。
- 安装授权、更新新增权限重新授权、随时撤销、审计。细分文件元数据/目录读、注册表、网络抓包/探测/联网、进程、系统、历史、插件通信、专属存储、GUI 等；最小权限默认，无间接越权。
- Python 和 TS/JS 采用混合运行时：项目级集中安装解释器和依赖、按需启动、权限和故障隔离；不要求用户提前安装 Python/Node.js。第三方各自依赖环境受统一管理。SDK 层权限不等同 OS 级沙箱，必须实际验证绕过系统接口、网络、文件、子进程等风险。原生插件不应直接信任其输入；禁用/撤权需真实生效。具体沙箱、运行时、IPC 由开发 Agent 调研并审批。

### 5.2 统一市场

官方插件、社区市场、已安装、更新管理为独立栏目；自定义源和本地包管理可独立入口，视觉由用户提供。插件、脚本和前端插件共用市场，不建设第二市场或开发者云平台。前端插件可以按 [AG-64](../AGENTS.md#ag-64) 扩展或替换 GUI。启用一套完整 GUI 时，停止其他完整 GUI 和渲染环境。官方默认 GUI 保持安装。权限、隔离、救援和删除确认仍由可信宿主执行。公开仓库索引及公开发布渠道，无账号绑定或云依赖。

第三方自由提交、发布和更新，不要求人工预审；自动格式、依赖、兼容性和基础安全扫描；区分官方、社区、未验证，展示源码、许可证、版本、权限；支持举报、下架及警告、签名/完整性验证、自定义源、本地导入。自由发布不等于默认信任。

复合包可包含多个 Python/TS/JS 模块、页面、组件、脚本、规则、配置、语言资源、依赖、权限、MCP/脚本扩展及文档；统一安装/更新/卸载和版本，内部能力独立启禁。脚本安装后默认不执行；修改可保存独立版本。正式对外发布必须用户确认，凭证存放本地安全存储，不能暴露给普通插件，不夹带监视数据。

### 5.3 脚本工作台

StrataScript 是官方插件而非每个插件的重复编辑器。Python、TS、JS；语法高亮、补全、诊断、创建/编辑/测试/调试/热重载、手动/事件/定时/条件触发、权限、依赖、资源、日志、历史、错误、版本与导入导出。其他插件注册接口，Core 提供统一运行时及隔离。StrataSnapshot 默认仅手动创建，自动默认关闭且无预设方案；用户或 Agent 通过开放接口自定义。StrataFilter、StrataRules、StrataTag、StrataStorage 等共享脚本体系。默认不提供预设自动化脚本，不允许普通脚本越过只读边界、救援通道或清理确认。

### 5.4 更新机制

Core、本机服务/驱动、官方插件、第三方插件、脚本及运行时独立版本管理；自动/手动、锁定、回退，版本/协议/依赖校验、更新包完整性和签名检查、失败回退、配置/历史保留。公开分发，不自动上传数据。内核驱动更新需重启时说明。开发阶段实现上述能力，不额外制作正式发行版。

## MCP 与临时救援

### 6.1 StrataMCP

仅本机 Agent；不开放局域网或公网。标准 MCP，候选 stdio 或回环传输，实际连接认证和进程身份校验由开发 Agent 验证，不能仅凭 localhost 即信任。插件启用后动态注册授权工具/资源/提示，禁用注销。独立 Agent 接入授权、撤销、调用审计及资源预算属于 WinStrata 自身接口保护，不管理外部 Agent 决策。

必须覆盖：

- 系统/硬件状态、软件生命周期及残留、文件/注册表/环境变量、进程/服务、抓包/流量/拓扑、签名/依赖/安全/更新、历史/全局搜索/时间线/快照/诊断等授权查询。
- 插件开发：查询市场避免重复、SDK/协议发现、创建项目和编辑代码、构建/验证/打包、测试/日志/热重载、本地安装及版本管理；支持外部 Agent 动态开发并扩展，无需重编译 Core。
- 脚本工作台：创建、读取、编辑、测试、调试、权限及依赖校验、启停、版本、触发条件、执行结果、资源和错误查询。
- 市场：依赖查询、打包、版本更新、生成说明及提交发布申请，正式对外发布用户确认；插件安装及新增权限按已确认的插件授权流程处理。
- StrataTag/Filter/Storage 等已授权能力、快照手动调用、资源及存储策略配置。历史分析模式仅提供相应历史数据及非采集功能；不隐式启动监视。

不内置 Agent，不提供通用管理员命令，不假设外部 Agent 平台安全。对来自文件、网络和插件的内容按不可信数据处理。

### 6.2 StrataRescue（唯一系统修改例外）

官方原生、默认关闭、不纳入首次引导或批量启用；临时通道，不带病毒库、异常判断、自动修复、独立救援业务页面或预设规则。用户主动启用通道后，仅通过 StrataMCP 向本机 Agent 暴露受限接口；关闭撤销通道。外部 Agent 的操作决策、逐项确认或自主程度由外部平台负责，WinStrata 不另外建设 Agent 管理系统。

| 允许 | 不允许 |
|---|---|
| 针对异常目标终止进程、终止进程树 | 任意管理员命令、Shell/PowerShell 执行、通用命令代理 |
| 隔离或删除异常文件 | 任意注册表、环境变量、服务、防火墙、安全策略修改 |
| 通过受控方式卸载异常软件、清除确认归属的残留文件 | 任意驱动加载/卸载、系统配置修复、其他用户的数据操作、第三方插件或脚本直接调用救援通道 |

正常卸载可能间接修改系统配置，必须验证卸载接口不会扩大成任意命令执行。WinStrata 负责接口边界、目标与参数校验、权限、真实结果和日志；不自行判定目标恶意。优先可逆处理、保护关键系统组件及安全边界，不把通道设计成绕过 Windows 保护的工具。具体目标身份验证、审计及安全实现由开发 Agent 提案。关闭通道后不得继续接受操作。仅在隔离测试环境验证危险操作，真实电脑须明确授权。
