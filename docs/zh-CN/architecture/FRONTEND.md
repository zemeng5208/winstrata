## GUI、初始化及运行状态

### 9.1 指定开源组件、动效与排版规范（已确认）

前端必须复用所有者指定的三个开源项目，不自行创造或重写已有 UI 组件，不擅自引入其他设计体系。以下为指定来源与用途，而非已经完成集成的声明。

| 指定项目 | 源码仓库 | 用途及约束 |
|---|---|---|
| Amicro — Micro transitions | [Subhan-code/Amicro--Micro-transitions-](https://github.com/Subhan-code/Amicro--Micro-transitions-) | 复用已有 UI 组件及微交互动效；优先使用上游现有实现，不重新创造同类组件或动效。 |
| Glasswork | [kubai087/glasswork](https://github.com/kubai087/glasswork) | Apple Liquid Glass 风格的液态玻璃按钮、玻璃材质及毛玻璃效果；使用上游可复用实现，不自行重新设计玻璃组件。 |
| shadcn-admin | [satnaing/shadcn-admin](https://github.com/satnaing/shadcn-admin) | 统一应用框架及排版参考，复用侧边导航、顶部区域、内容区、仪表盘、表格及设置页面等适用布局；允许根据 WinStrata 功能进行小幅布局调整。 |

三个仓库的 GitHub 许可证元数据均显示 MIT；实际引入前仍须核对所选版本的 LICENSE、第三方素材与传递依赖许可，保留原始版权和许可声明。开发 Agent 应检查真实源码、适用组件、可复用方式、WebView2 兼容性、性能与依赖，提交具体版本及集成方案；不得把上游演示页面或未验证的接口直接当作已可用组件。指定项目的设计方向已获确认，具体版本、额外依赖和超出范围的修改仍遵守 AG-08、AG-39 审批规则。

### 9.2 三套内置默认主题

| 主题 | 强制视觉要求 |
|---|---|
| 白色圆角亚克力（White Acrylic） | 白色/浅色为主，圆角、亚克力质感，统一按钮、面板与控件。 |
| 黑色圆角亚克力（Black Acrylic） | 黑色/深色为主，圆角、亚克力质感，保证文本、边界与状态的可辨识性。 |
| 液态玻璃（Liquid Glass） | Apple Liquid Glass 风格按钮与毛玻璃面板结合，使用 Glasswork 的适用材质实现。 |

三个主题必须完整内置，覆盖主窗口、仪表盘、官方插件页面、设置、插件市场、初始化向导及弹窗。通过共享组件与项目级主题配置实现运行时切换并保存用户选择，不维护三套重复的业务页面。首次启动具体选中哪套主题、主题参数及材质细节由开发 Agent 提案，不擅自指定。主题不等同于仪表盘布局，仍仅保存一套首页布局。

### 9.3 组件复用与排版边界

- UI 基础组件、按钮、表单、弹窗、导航、动效等优先直接复用上述指定项目的真实已有实现；禁止自行创造替代组件、重复造轮子或引入未经批准的组件库。
- 允许组合现有组件、绑定真实后端数据、添加业务逻辑适配及必要主题参数；允许对 shadcn-admin 的排版、间距、密度及内容区布局进行小幅适配，保留总体设计体系，不将该许可扩大为重新设计基础组件。
- 指定资源确实缺少所需组件或无法满足功能、安全、兼容性、性能要求时，报告缺口、复用候选及证据，取得所有者批准后再实施替代方案；不得自行创造组件填补缺口或使用假入口。
- 官方插件与第三方插件的宿主 UI 接入统一主题、共享组件及页面注册规范；项目级集中管理组件源码/依赖及主题资源，禁止在各插件复制整套 UI。
- 玻璃模糊、折射及微动效须通过真实 Windows WebView2 运行验证；控制持续渲染、GPU/CPU、内存和 I/O 开销，非可见区域停止无效动效，遵守 [§10](../roadmap/ACCEPTANCE.md#section-10) 性能目标。必要兼容或低动效处理不得擅自取消已确认的主题能力。
- 真实 GUI 验收必须覆盖三主题切换、保存与恢复、同一业务页面的数据/功能一致性、插件动态页面、窗口缩放及不同语言下的可读性；记录上游组件来源与适配内容。

### 9.4 GUI 通用行为

前端与业务逻辑、数据状态及插件协议解耦；所有入口真实可用，不能用假数据填补未实现能力。中英文完整翻译，支持运行时切换、英文回退与插件语言资源；不出现无意中英文混杂。

首次启动向导包括语言、有效存储位置、插件启用选择、监视范围、保留期限（默认永久）、开机自启动（默认关）、可选加密、MCP 选择及初始基线；非必要项可跳过、可中断继续。StrataRescue 排除在批量启用外，自动快照和预设脚本不启动。仅启动用户启用的采集。初始基线按选择范围建立，不对未选磁盘重复扫描。

主窗口提供单一自定义仪表盘，插件动态提供组件，添加/移除/拖拽/缩放/排列、独立设置和刷新频率、自动保存、恢复默认。不提供多套仪表盘布局或独立组件市场；不可见组件停止无用渲染，不影响后台监视。

全局搜索支持软件名、路径、注册表、进程、PID、IP/域名/端口等，组合/正则/时间和类型筛选、统一对象档案、关系图、时间线、原始证据跳转及可信度。插件管理独立栏目见 [§5](EXTENSIONS.md#section-5)。

关闭窗口时询问：最小化至托盘继续监视，或完全退出、停止采集、刷新待写入数据并安全释放资源；可记住选择，设置中修改。主动启动、可选开机启动；关闭 GUI 不等同退出。禁止未经授权常驻监视或自动开启插件。

工作模式：实时监视与历史分析运行时切换，无需重启；历史模式停止采集并安全释放非必要驱动，只查询历史/抓包/快照/软件档案，允许历史 MCP 查询；模式切换记录中断区间，保存待写入数据。全局与插件独立暂停/恢复，自定义磁盘、路径、文件类型、进程、软件、注册表及网卡范围，动态配置。区分主动暂停、禁用、故障、数据丢失。所有异常状态（加载、空数据、权限不足、不支持、离线、存储异常等）须真实展示。
