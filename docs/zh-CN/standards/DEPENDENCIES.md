# 依赖与配置规范

[English](../../standards/DEPENDENCIES.md) · [文档索引](../INDEX.md)

<a id="ag-08"></a>

### AG-08 技术资料验证与开源复用

使用第三方库/API 前查官方文档、源码和真实接口；禁止编造、未经验证使用废弃或不兼容接口、未验证宣称可行。新功能优先调研可复用开源项目，报告仓库/文档、覆盖/缺失、许可证、维护/安全/质量、性能、双环境构建、集成/替换成本、直接用/部分复用/Fork/自研建议；用户决定是否采用。未经批准不引入或复制；遵守版权，不因复用降要求或改变架构。子 Agent 可初筛，主 Agent 验证，记录选型依据。

<a id="ag-19"></a>

### AG-19 仓库洁净度与构建环境

不提交编译产物、缓存、临时文件、调试日志、测试数据、真实监视/抓包/数据库、密钥和个人配置、无用脚本、废弃/重复文档、未经批准二进制或 Agent 临时文件。保留有价值历史记录；集中构建/临时目录和可复现工具链，完善 gitignore、敏感信息及污染检查，Commit/PR 前检查。

<a id="ag-35"></a>

### AG-35 跨平台构建一致性（按 AG-49 最新修订）

维护 Linux/Windows 构建能力、统一依赖/参数/产物/路径；不引入未批准 Windows 专属构建限制，不硬编码环境。每个开发者验证其实际可用环境，不强制每个 PR 双端构建；记录未执行环境，Linux 构建不等于 Windows 运行。已确认跨平台问题及时修复重验并阻断；工具链文档全局同步，并按 [AG-65](../AGENTS.md#ag-65) 与[平台实现记录与构建隔离规范](PLATFORM_ISOLATION.md)落实目标平台构建与打包隔离。

<a id="ag-39"></a>

### AG-39 项目级依赖和供应链

Rust/npm/Python/SDK/WDK/工具链/外部开源依赖集中版本、锁文件、声明、路径；成员按需引用，禁止无必要多版本及散落环境/cache。第三方插件运行依赖统一隔离管理。新增/升级/降级审批、来源/许可证/漏洞/维护检查；删除后清理，实际依赖变更当前环境构建及整体回归（不强制双端）。记录直接用途、版本和依据。禁止为简单功能引入庞大依赖。

<a id="ag-40"></a>

### AG-40 统一配置

Core 统一配置注册、读取、更新、校验、迁移，插件声明自己的结构；开发/构建/运行/用户配置分类集中。禁止重复全局参数、随意独立配置和直接读环境变量；动态更新、默认、权限隔离和敏感项安全存储；升级不丢用户配置，变更全局影响检查。

<a id="ag-54"></a>

### AG-54 依赖完整性及复现

无需每次重装依赖，允许复用正确环境/cache；每次开发先检查并补齐已批准依赖、版本及实际解析路径。禁止未声明本地库/工具、缺依赖就跳过、临时未批准安装。正式文档可复现，必要时干净构建检查污染/可复现性。

<a id="ag-55"></a>

### AG-55 工具能力及依赖路径

开发前核实工具、权限、网络、环境和可调用子 Agent；不足如实说明，禁止假装执行命令、文件访问、构建、测试或子 Agent，不为工具限制擅改架构。依赖指向项目级统一管理、统一解析；不硬编码个人路径、不引用其他项目/临时依赖、不因路径错重复安装或复制、不散布环境；移动目录/切换环境仍正确。SDK/WDK 外部工具链统一配置解析，不必复制仓库。结果纳入前置清单。

<a id="ag-56"></a>

### AG-56 跨环境与工作目录隔离

本地、云端、Worktree 遵循统一规范，区分工作目录、产物、运行状态；证据注明实际环境，不混用。机器专属路径/配置不入项目，切换检查项目依赖和路径、按 Git/文档恢复、不重复实现；不强制多环境，开发者负责。
