### AG-23 安全与最小权限

默认最小权限；所有外部输入校验，不默认信任插件、MCP、网络、导入数据。Rust unsafe 限定范围并记录必要性/安全前提；严格内核、用户态、服务、插件信任边界。禁止安全绕过及未授权数据外发。每 PR 评估攻击面；安全缺陷全局排查/修复/重验，未修复阻断。必须有真实安全证据。

<a id="ag-47"></a>

### AG-47 内核驱动专项

只采集/传输，官方支持接口优先；不未公开/未验证接口或非标准 hook，不以绕过签名、Secure Boot/HVCI 为正式运行。控制内存、锁、IRQL、缓冲、回调，回调不做耗时分析/非必要 I/O。真实加载/卸载、恢复、泄漏/蓝屏风险、高负载/长期验证；内核缺陷最高优先级，未真实 Windows 验证不标完成；同步文档。
