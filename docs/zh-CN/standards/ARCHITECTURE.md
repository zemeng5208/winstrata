### AG-30 前端设计

严格执行 [§9.1–§9.3](../architecture/FRONTEND.md#section-9) 的权威前端规范：指定 Amicro、Glasswork、shadcn-admin 与 UI Moments，内置白色圆角亚克力、黑色圆角亚克力、Apple 液态玻璃按钮 + 毛玻璃三套主题。UI Moments 只作为已有交互组件与动效的复用来源；其组件示例须先完成许可和版本审查，不因指定而批准 Fluent UI 或 Astryx 作为产品依赖。禁止自行创造、重复实现已有 UI 基础组件或擅自更换组件库、视觉、配色及交互；允许复用组合与业务适配，shadcn-admin 排版可小幅调整。遇组件缺口先报告并申请批准，不自行补造。统一插件扩展、窗口尺寸适配、真实数据和异常展示；验证三主题切换、持久化、真实交互与性能。可替换性、内置恢复界面、解耦、可信宿主、单一市场和来源追踪是 [AG-64](../AGENTS.md#ag-64)。本条不重复其定义。UI 文档遵守专业写作，不记无意义过程。根 `AGENTS.md` 必须索引本条与 [§9](../architecture/FRONTEND.md#section-9) 对应的正式前端规范。

<a id="ag-32"></a>

### AG-32 兼容性与迁移

公共接口/事件/协议/数据库/配置版本化；改动检查所有直接间接调用、官方插件、SDK/MCP。破坏性变更须批准；数据/用户配置不丢失；验证升级、回退和迁移失败。避免长期无必要双实现，批准废弃完整清理代码/测试/文档/依赖，纳入整体回归。

<a id="ag-42"></a>

### AG-42 Core 与插件职责

Core 仅公共基础设施，业务由插件实现；不为特定插件硬编码业务、不绕标准接口，不重复底层采集。统一能力契约，共享按需；全部业务插件禁用 Core 仍独立稳定。新增核心能力说明通用性、必要性、影响并审批，架构审计重点检查。

<a id="ag-43"></a>

### AG-43 插件独立性与可替换性

独立加载、启动、暂停、停止、更新、恢复；禁用释放专属资源/订阅，重启恢复配置状态。不硬编码其他插件名称/ID/路径，不直接读私有实现；标准能力、服务、事件。官方不可卸载但可禁用/兼容替代，不要求修改 Core/无关插件，不丢历史。官方默认 GUI 按 [AG-64](../AGENTS.md#ag-64) 保持安装，并作为恢复界面；禁用第三方 GUI 不是卸载官方 GUI。真实热插拔/替换测试。救援等特殊授权不外溢。

<a id="ag-44"></a>

### AG-44 统一存储与共享数据

Core 统一存储/查询/索引/加密/保留；不为插件重复建数据库。原始数据原则上存一次、对象标识共享，插件专属结构统一管理权限；不重复存可计算数据，必要性能缓存除外；抓包等专用格式仍统一管理。备份迁移一致，结构变更全局分析及真实测试，效率纳入性能。

<a id="ag-45"></a>

### AG-45 并发与异步

集中公共运行时/任务调度，插件申请资源；不重复线程池/运行时，支持优先级、取消、超时、限制；禁用安全终止专属任务并释放。防线程泄漏、死锁、无界队列、无限等待；高吞吐专用机制需验证，不阻塞 GUI，真实并发/压力/长期测试。

<a id="ag-46"></a>

### AG-46 事件总线与传输

统一事件格式、类型、时间、来源和标准通信；订阅、过滤、批处理、优先级；低拷贝低序列化，背压有界，禁止静默丢失；不私设通道绕权限，禁用解除订阅。协议变更检查所有生产消费方，真实高吞吐/突发测试数据完整性。
