# 文档规范

[English](../../standards/DOCUMENTATION.md) · [文档索引](../INDEX.md)

<a id="ag-05"></a>

### AG-05 验收证据、开发记录与低成本子 Agent

每完成模块/子模块、PR、长会话、重要变更/阻塞或获得有效验证结果，维护模块及全局文档，记录实际命令、结果、环境、变更文件、测试/构建/性能、剩余问题和下一步。未经执行明确未验证；不只保留在对话中。可委托廉价模型整理，主 Agent 提供真实证据并负责核实；不可用则自行完成。

<a id="ag-06"></a>

### AG-06 上下文恢复与全局文档一致性

新 Agent、压缩/中断/切换后按规范、决策、进度、前序 PR、错误、交接恢复上下文并输出清单。任一文档改动递归检查上下级、直接/间接引用、跨模块、全仓库过期内容/链接/示例和双语语义；维护引用索引、权威来源及影响清单（已更新/无需更新/待审批）。低成本子 Agent 可扫描，主 Agent 核实；不无意义重写。

<a id="ag-25"></a>

### AG-25 错误、降级与独立记录

统一错误类型/码/诊断；禁止静默忽略、失败返回成功、无限重试掩盖故障。插件故障不影响无依赖模块，采集异常、缺失、降级可感知可追溯，正常后安全恢复，诊断不泄露敏感数据。独立全局和模块错误文档，字段见 [§12.2](#section-12)，即时更新、保留已解决历史、重验前不关闭，与 PR 阻断联动；运行日志与工程记录分离。可委托廉价子 Agent 核对。

<a id="ag-28"></a>

### AG-28 变更可追溯与专业文档

实质变更关联需求/决策/错误/PR；准确 Commit/PR 描述、ADR、被替代决策、删除原因/影响/批准。禁止来源/目的不明。文档客观、简洁、专业、准确；禁止防御性写作、辩解、推卸责任、夸大、用户口语/情绪/私人对话或个人信息、原始聊天全文。口语转正式技术规范不改原意；错误聚焦事实、根因和解决。

<a id="ag-29"></a>

### AG-29 语言与注释

标识符、文件/目录、Commit、PR 标题/描述、协议字段英文；代码注释简体中文；正式文档和 GUI 简中/完整英文。注释简洁说明功能、实现、设计约束及实际修改，保留有意义的修改记录，不写思考过程、口语、防御性说明、奇怪修改过程或过期注释。详细历史用 Git 和开发文档，前端设计只描述功能/布局/交互和必要变更。

<a id="ag-36"></a>

### AG-36 全局进度

统一权威进度文档，覆盖 PR、核心、官方插件、原子需求、真实验收、错误、阻塞、待决及下一步；明确状态，按批准任务/真实验收计算完成度，不主观估百分比。回归调整验收状态；模块与全局一致，廉价子 Agent 可维护，主 Agent 核实。

<a id="ag-61"></a>

### AG-61 需求追踪

每项批准需求唯一编号，统一追踪矩阵关联模块、PR、验收和实际证据；长对话/压缩/模块合并/Agent 切换不遗漏，不以未实现标完成。变更全局影响分析，实时维护与权威进度一致，最终逐项核验全需求。

<a id="section-12"></a>

## 权威文档体系（提案）

文档入口见 [文档索引](../INDEX.md)。简体中文和英文正式文档使用相同的相对结构和稳定编号。每项事实只指定一个权威来源，通过引用关联。模块文档补充专属设计、实现、进度、测试和错误记录，不能覆盖全局规则。

### 12.1 文档联动

任何代码、接口、配置、依赖、设计、错误、进度或测试变更，必须检查全仓库直接/间接引用、上下层和跨模块文档、双语语义、失效链接、旧接口、示例及 PR 计划。输出影响清单：已更新 / 无需更新及理由 / 待审批。实现与关联文档同一 PR 同步，不推迟。禁止反向修改权威规范掩盖错误；独立规范变更申请审批合并后才生效。

每完成模块/子模块、PR 或长会话，发生重要变更、阻塞或获得有效验证结果时更新对应文档、全局进度及交接；错误即时记录。可委托低成本子 Agent 扫描和整理，主 Agent 提供真实 diff、结果并核实；子 Agent 不改已批准规范。文档使用专业语言，不记用户私人内容、原始聊天、辩解、自我评价、奇怪修改过程。代码注释中文，简单说明功能/修改，保留有意义的修改记录；完整历史通过 Git/正式文档保存。英文代码标识、文件名、Commit、PR 标题/描述、协议字段；正式文档简中/英。

### 12.2 记录字段（统一模板，不为每条记录新建文件）

| 记录 | 必要字段 |
|---|---|
| 需求 | ID、已确认要求、来源/批准记录、模块、PR、验证标准、实际证据、状态 |
| ADR | ID、决策、依据、备选、影响、批准状态、替代记录 |
| 全局进度 | PR 计划号、状态、负责人、依赖、验收结果、未解决错误、下一步 |
| 错误 | Error ID、发现时间/PR、环境、复现、证据、根因、影响、修复、重验、状态、关联 |
| 技术假设 | ID、假设、影响、验证方法、环境、证据、状态、结论/审批 |
| 性能/测试 | 基线 commit、环境、场景、命令/步骤、预期与实际、指标、错误、证据位置、是否验证 |
| 会话交接 | 当前分支/commit、工作树、已实现/待验证、阻塞、剩余任务、文档状态、接手责任 |

错误状态：未解决、修复中、待验证、已解决。保留历史，未经重验不得关闭。进度状态：未开始、开发中、待验证、待审查、待合并、已验收；回归时调整状态。完成度依照批准的实际验收任务计算，不按代码行数或主观百分比。完整验证证据与运行环境对应，不提交真实隐私数据或大体积原始日志。
