# 贡献流程

[English](../../CONTRIBUTING.md)

阅读 [Agent 规范](AGENTS.md)、[项目计划](roadmap/PLAN.md)和 [Git 与 PR 规范](standards/GIT_AND_PR.md)。从获批基线创建开发分支。实施前确认计划编号、范围、前置条件、合并位置和验收证据。范围、架构、依赖和强制规范的变更须先获批准。

按 [PR 审核模板](../../.github/pull_request_template.md)用英文提交 PR，列出真实差异、测试环境、结果和待验证事项，并同步受影响的双语文档。项目所有者按批准的顺序审核和合并。安全问题走[安全报告流程](SECURITY.md)。
