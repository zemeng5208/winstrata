# 过滤插件错误登记

[English](../../records/modules/strata-filter.md) · [全局登记](../ERRORS.md) · [过滤插件](../../architecture/FILTER.md)

`plugins/strata-filter` 的权威错误记录。

本插件没有记录错误。这台 Linux 编写主机没有执行 Windows 过滤测试。该限制是 [OI-052](../OPEN_ITEMS.md#oi-052)。官方过滤页没有在 Windows 上打开。该限制是 [OI-053](../OPEN_ITEMS.md#oi-053)。这两项都不是错误。[ERR-021](strata-services.md#err-021) 属于 `plugins/strata-services`，并仍在那里开放。[ERR-022](strata-script.md#err-022) 在脚本登记中保持已解决。
