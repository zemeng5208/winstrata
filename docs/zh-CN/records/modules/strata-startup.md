# 启动插件错误登记

[English](../../../records/modules/strata-startup.md) · [全局登记](../ERRORS.md)

`plugins/strata-startup` 的权威错误记录。

本插件没有记录错误。这台 Linux 编写主机没有观察到 Windows 的 Run 键、启动文件夹、StartupApproved、快捷方式本地路径和任务计划程序。该限制是 [OI-044](../OPEN_ITEMS.md#oi-044)。它不是错误。[ERR-021](strata-services.md#err-021) 属于 `plugins/strata-services`，并在那里保持开放。
