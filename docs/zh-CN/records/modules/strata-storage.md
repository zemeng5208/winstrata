# StrataStorage 错误登记

[English](../../../records/modules/strata-storage.md) · [全局登记](../ERRORS.md) · [存储插件](../../architecture/STORAGE.md)

`plugins/strata-storage` 的权威错误记录。

本模块没有错误。Linux 编写主机没有运行 Windows 工作区作业。该缺口是 [OI-058](../OPEN_ITEMS.md#oi-058)。Windows 存储页是 [OI-059](../OPEN_ITEMS.md#oi-059)。托盘警告是 [OI-057](../OPEN_ITEMS.md#oi-057)。MCP 配置是 [OI-060](../OPEN_ITEMS.md#oi-060)。[OI-024](../OPEN_ITEMS.md#oi-024) 仍是待所有者决定的事项。[OI-051](../OPEN_ITEMS.md#oi-051) 仍属于计划 026。本文件不改写它们。[ERR-019](../ERRORS.md#err-019) 至 [ERR-024](strata-script.md#err-024) 保持已有记录。
